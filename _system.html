01 — Tokens

Colour & geometry

Palette retuned from the v1 purple+gold system. Deeper brand purple passes AA on paper; gold shifts from candy to bronze. Light and dark values sit side-by-side so dark-mode derivations are auditable.

Category chip rule: the v1 search used a 4-colour rainbow (Interface purple, Memory gold, Security green, Analog blue). Phase 1 collapses this to a single neutral chip with an optional ink-coloured dot — see Tags & Chips.

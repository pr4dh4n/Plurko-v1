## SHARED CONTEXT (paste this at the TOP of every prompt)

```
CONTEXT — You are building sections for a semiconductor IP marketplace website called PlurkoTech. Write production-quality, hand-crafted HTML and CSS. No frameworks, no Tailwind, no React — just clean semantic HTML5 and vanilla CSS. The code must look like it was written by a senior frontend developer, not generated by AI. That means: meaningful class names (BEM-ish but not religious about it), logical CSS property ordering, no unnecessary wrappers, no excessive comments, subtle but intentional animations. Use CSS custom properties for all colors.

DESIGN SYSTEM (use these exactly):
- Fonts: Poppins (headings, 600-800), Raleway (body, 300-500), JetBrains Mono (labels/technical, 400-700)
- Primary: #744897 (purple), Light: #987AB3, Dark: #4E3166
- Accent: #FFD166 (gold), Dark: #E8B84B
- Light theme: bg #FFFFFF, bg-alt #F7F5F2, text #222222, text-light #666666, text-muted #999999, border rgba(34,34,34,0.08)
- Dark theme: bg #1A1A1E, bg-alt #2A2A2E, text #E8E8E8, text-light #AAAAAA, text-muted #777777, border rgba(255,255,255,0.08)
- Theme switching via [data-theme="dark"] and [data-theme="light"] selectors on <html>
- Easing: cubic-bezier(0.16,1,0.3,1) for reveals, cubic-bezier(0.4,0,0.2,1) for hover
- Border-radius: 16px cards, 12px inner elements, 100px pills/buttons
- Max container: 1400px centered
- Section padding: clamp(48px, 6vw, 80px) vertical, clamp(24px, 4vw, 96px) horizontal
- Card hover: translateY(-4px) + border-color change + box-shadow. NEVER use scale transforms on cards.
- Scroll reveal: elements start at opacity:0, translateY(30px) and transition to visible. Use class "gsap-up" with CSS variable --i for stagger index.

BOTH THEMES REQUIRED: Every element must look good on both white (#FFFFFF) and near-black (#1A1A1E) backgrounds. Provide [data-theme="dark"] and [data-theme="light"] overrides where needed.

OUTPUT: Only the <style> block and <section> HTML. No <head>, no <body>, no JavaScript unless specifically asked. Keep the CSS terse — no extra whitespace in selectors.
```
